Track Circuit Signal Quiz — Multiple Trains

Set each signal to the correct aspect — each line can have 1, 2 or 3 trains on it

How it works: trains travel up each of the 6 lines. Each line has 1, 2 or 3 trains (blue blocks) sitting on it. For every signal, find the nearest train ahead of it: the signal immediately behind that train shows red, the next one back shows single yellow, the next one back from that shows double yellow, and any signal further back than that (or with no train ahead of it at all) shows green. If a second train is further back, it creates its own red/single/double cascade behind it the same way — just work out which train is nearest to each signal.

Pick an aspect for all 36 signals, then press Check Answers. Press New Layout to reshuffle the trains and try again.
